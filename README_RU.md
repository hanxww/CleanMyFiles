Зачем нужен CleanMyFiles?

Многие программы для очистки диска работают по одному сценарию: показывают большое число, называют файлы «мусором» и предлагают удалить всё одной кнопкой.

CleanMyFiles устроен наоборот. Его задача — сначала показать и объяснить, что занимает место, а удалять только то, что пользователь выбрал сам.

Сканирование диска
        ↓
Понятная картина занятого места
        ↓
Дубликаты, большие и старые файлы, кандидаты на очистку
        ↓
Ручной выбор
        ↓
Перемещение в системную Корзину

Пути, результаты анализа и содержимое файлов остаются на вашем компьютере.

[!IMPORTANT]
Раздел очистки показывает кандидатов, а не гарантированно ненужные файлы. CleanMyFiles специально не принимает разрушительные решения за пользователя.

Безопасность заложена в архитектуру

CleanMyFiles ближе к анализатору диска, чем к «очистителю в один клик».

После сканирования ничего не выбирается автоматически.

Само сканирование ничего не удаляет.

Дубликат считается точным только после полного совпадения хеша содержимого.

Функция Select extra copies оставляет как минимум одну копию в группе невыбранной для проверки.

Кэши, временные файлы и установщики показываются осторожно и требуют ручного подтверждения.

Символические ссылки не обходятся рекурсивно.

Удаление идёт через системную Корзину, а не через безвозвратное стирание.

Данные анализа остаются локально на устройстве.

Даже полностью идентичный файл может быть нужен программе по конкретному пути. Перед удалением всегда проверяйте выбор.

Запуск из исходников

Требования

Node.js 20+

Rust stable; на Windows — MSVC toolchain

Microsoft C++ Build Tools с компонентом Desktop development with C++

WebView2 на Windows (обычно уже есть в современных Windows 10/11)

Windows

Если Rust ещё не установлен:

winget install --id Rustlang.Rustup

После установки открой терминал заново:

rustup default stable-msvc

Затем:

git clone https://github.com/hanxww/CleanMyFiles.git
cd CleanMyFiles
npm install
npm run desktop:dev

Или запусти:

dev-windows.cmd

Сборка Windows-установщика

npm install
npm run desktop:build

Или:

build-windows.cmd

Скрипт пытается самостоятельно найти Visual Studio Build Tools и подключить MSVC environment, если link.exe не доступен в текущем терминале.

Результат сборки появится здесь:

src-tauri\target\release\bundle\
├─ nsis\
│  └─ CleanMyFiles_*_x64-setup.exe
└─ msi\
   └─ CleanMyFiles_*_x64_en-US.msi

[!NOTE]
Для создания MSI в Windows может потребоваться дополнительный компонент VBSCRIPT. Для большинства пользователей NSIS setup.exe остаётся более простым форматом распространения.

Browser preview

Для работы только над интерфейсом можно запустить веб-режим:

npm install
npm run dev

В браузере используются демонстрационные данные. Обычная веб-страница не может рекурсивно анализировать произвольные корни дисков с тем же доступом к файловой системе, который есть у Tauri-приложения.

Как ищутся дубликаты

CleanMyFiles не делает полный хеш каждого файла без необходимости.

Файлы
  │
  ├─ группировка по размеру
  │
  ├─ быстрый fingerprint для кандидатов
  │
  └─ полный BLAKE3 для финальной проверки
          │
          └─ группа точных дубликатов

Полные хеши кэшируются на время текущей сессии, поэтому повторные проверки обходятся дешевле.

Тяжёлое сканирование выполняется не в webview-потоке, а в blocking worker pool Tauri. Прогресс передаётся обратно в интерфейс во время обхода файловой системы и проверки кандидатов на дубликаты.

Roadmap

Сейчас основной приоритет — сделать анализ диска ещё быстрее, понятнее и безопаснее, прежде чем добавлять более агрессивные механизмы очистки.

В планах:

более наглядная визуализация диска

ускорение повторных сканирований и постоянный кэш метаданных

улучшенные детекторы системных кэшей

дополнительные фильтры и исключения

полноценные сборки и тестирование macOS/Linux

более удобный release/update flow

Подробности находятся в ROADMAP.md.

Участие в разработке

Bug reports, тестирование на разных системах и небольшие сфокусированные pull request'ы приветствуются.

Перед крупными изменениями прочитайте CONTRIBUTING.md. Для сообщений, связанных с безопасностью, используйте инструкции из SECURITY.md.
